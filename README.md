# Husridge Web Application

A React-based web application for managing user authentication and billing integrations.

## Features

-   User authentication with email verification
-   Secure payment processing via Paystack integration
-   Centralized billing management
-   Form validation with Formik and Yup
-   Responsive UI with Tailwind CSS
-   TypeScript for type safety

## Tech Stack

-   React 18
-   TypeScript
-   Vite
-   Tailwind CSS
-   Mantine UI
-   Formik & Yup
-   React Router
-   Paystack Payment Gateway
